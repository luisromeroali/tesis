# Eunices

Estructura base para el desarrollo del proyecto Eunices.

## 📁 Estructura del Proyecto

```text
Eunices/
├── docs/                 # Documentación técnica, requerimientos y diagramas
├── public/               # Archivos estáticos públicos accesibles directamente
├── src/                  # Código fuente de la aplicación
│   ├── assets/           # Recursos estáticos internos (imágenes, iconos, estilos)
│   ├── components/       # Componentes reutilizables de interfaz o módulos
│   ├── config/           # Configuraciones generales y variables de entorno
│   ├── controllers/      # Controladores o manejadores de lógica de entrada
│   ├── models/           # Definición de modelos de datos, esquemas o tipos
│   ├── routes/           # Definición de rutas o endpoints
│   ├── services/         # Lógica de negocio y conexión con APIs/servicios
│   └── utils/            # Funciones utilitarias y helpers
├── tests/                # Pruebas unitarias, de integración o e2e
├── .env.example          # Plantilla de variables de entorno
├── .gitignore            # Archivos y directorios ignorados por Git
└── README.md             # Documentación principal del proyecto
```

## 🚀 Repositorio

- **GitHub Remote:** `https://github.com/luisromeroali/tesis.git`
- **Rama principal:** `main`

## 🛠️ Primeros Pasos

1. Copiar las variables de entorno de ejemplo:
   ```bash
   cp .env.example .env
   ```
2. Iniciar el desarrollo según el stack o framework seleccionado.
